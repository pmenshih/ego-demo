# Тесты лабораторных

Тесты читают артефакты из `labNN/artifacts/` и пересчитывают из них все, что можно пересчитать. Код работы они не запускают и не импортируют: запуск делает CI, локально его делаете вы.

```
python lab02/run.py --fast && pytest tests/test_lab02.py
```

Пока `labNN/run.py` содержит `NotImplementedError`, модуль тестов этой работы пропускается.

В CI тесты всегда берутся из репозитория курса, а не из вашей копии, поэтому правки в `tests/` на проверку не влияют. Если тест кажется неверным, пишите преподавателю.

## Пороги

Порог доли внимания на антецедент не ниже 0.2. Пороги считаются по быстрому режиму, потому что CI запускает именно его.
